# AUTOSAT Nigeria — Luxury Automotive Digital Flagship

> **"Satisfying Automobile Desire"**  
> An ultra-curated single-dealership marketing website for AUTOSAT Nigeria, located in Victoria Island, Lagos.

---

## Brand & Aesthetic Overview
- **Aesthetic**: Modern, calm, and spacious Apple-Store-inspired luxury gallery.
- **Palette**: Deep Void Black (`#0A0A0A`), Off-Black Surface (`#141414`), Coral energy accents (`#E85A3B`), and Teal trust accents (`#0E7A72`).
- **Typography**: Inter Tight geometric display headings, Playfair Display editorial accents, and clean Inter body copy.
- **Localization**: Tailored specifically for Nigeria (Lagos, Abuja, Port Harcourt), with 100% authentic customs duty documentation, covered door-to-door transit, and pricing strictly in Nigerian Naira (NGN).

---

## Features
- **Official Brand Emblem**: Circular badge with transparent framing, used as the site logo and favicon.
- **Hero Centerpiece**: Full-bleed cinematic showcase featuring the Porsche 911 GT3 Touring.
- **Curated Inventory**: Clean product-style hardware cards with 0–60, HP, speed, and real-time NGN pricing.
- **Interactive Vehicle Dossier**: Full specification and verified paper audit modal.
- **Why Choose Us**: Transparent 3-pillar customer value propositions.
- **Founder Profile**: Executive spotlight on Marcus Babatunde Vance.
- **Services**: Custom sourcing, flexible car financing, covered home delivery, and trade-in swaps.
- **Customer Reviews**: Height-locked, zero-shift smooth review carousel.
- **Social & Contact**: Official WhatsApp, Instagram, and TikTok integrations with interactive showroom visit scheduling.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/Dauda8110/Autosat.git

# Navigate to project directory
cd Autosat

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
Outputs static production bundle to `dist/`.
